# Glossary

## Key Technical & Architectural Terms

- **Face Embedding:** A high-dimensional numerical vector (e.g., 512 floating-point values generated by InsightFace or FaceNet) that mathematically encodes the unique spatial geometry and features of a human face.
- **Vector Database (Qdrant):** A specialized database engine designed to store, index, and query high-dimensional vector embeddings rapidly using distance metrics rather than exact string equality.
- **Cosine Similarity:** A mathematical metric measuring the cosine of the angle between two multi-dimensional vectors. Used in NeuroTwin to calculate the similarity score between a freshly captured face embedding and indexed person embeddings in Qdrant.
- **Foreground Service:** An Android system component that executes long-running background operations while displaying a persistent system notification to the user, preventing the Android OS from killing the camera capture process.
- **ADR (Architecture Decision Record):** A standardized document format capturing an important architectural decision made along with its context, considered options, and technical rationale.
- **MOC (Map of Content):** A central index note in Obsidian that organizes and links to all related notes within a specific vault or project domain.
- **Retrieval-Augmented Generation (RAG):** An AI architectural pattern where relevant external knowledge is retrieved from a database based on input context, then injected into an LLM prompt to ground generation. 
  
  > [!note] NeuroTwin RAG Pattern
  > NeuroTwin utilizes the classic RAG pattern, but adapts it specifically for cognitive assistance: instead of searching unstructured text documents, it retrieves personalized entity profiles, life stories, and memories indexed against face and object embeddings.
