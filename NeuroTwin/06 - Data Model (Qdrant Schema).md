# Data Model (Qdrant Schema)

## Rationale for Vector Database Architecture

NeuroTwin utilizes **Qdrant** as its primary vector memory engine. 

Traditional relational (SQL) or document (NoSQL) databases rely on exact keyword or key-value lookups. However, visual face recognition and natural language memory retrieval rely on high-dimensional similarity matching:
- **Facial Features:** Represented as 512-dimensional floating-point vectors generated by InsightFace. Matching requires calculating vector distances (Cosine Similarity) rather than string comparisons.
- **Semantic Memories:** Textual life stories and anecdotes can also be embedded for semantic retrieval when patients ask open-ended questions.

---

## 1. `people` Collection Schema

The `people` collection stores facial vector embeddings alongside rich personal metadata payloads populated by the caregiver.

### Vector Configuration
- **Distance Metric:** Cosine Similarity (`Cosine`)
- **Dimensions:** `512` (InsightFace / FaceNet standard output)

### Point Payload Structure

## 2. `objects` Collection Schema

The `objects` collection tracks known physical items (e.g., reading glasses, car keys, medicine organizer, wallet) observed by the vision pipeline over time.

### Vector Configuration / Index
- **Index:** Payload-indexed on `object_class` and `timestamp`.

### Point Payload Structure

```json
{
  "id": "uuid-v4-string",
  "payload": {
    "object_id": "obj_glasses_01",
    "object_class": "reading_glasses",
    "label": "Blue Reading Glasses",
    "last_seen_timestamp": "2026-08-19T16:45:12Z",
    "last_seen_location": "Living Room Coffee Table",
    "confidence": 0.94,
    "ble_tag_id": "BLE-TAG-8821-OPTIONAL",
    "bounding_box": {
      "x_min": 0.25,
      "y_min": 0.40,
      "x_max": 0.45,
      "y_max": 0.55
    }
  }
}
```

## Payload Indexing & Performance Strategy

To ensure sub-millisecond retrieval on the M4 server:
- **Payload Indexing:** Create explicit Qdrant payload indices on `person_id`, `name`, `relationship`, and `object_class`.
- **Filtering:** Vector searches support filtered queries (e.g., match face vector AND filter by active household profile ID).
